📌 Overview

Sundown Studio is a high-end creative website experience designed with modern animations, polished UI/UX, and a fully responsive structure.
Built with pure frontend technologies, it blends smooth interactions, video backgrounds, elegant transitions, and a luxury-aesthetic design suitable for agencies, branding studios, and portfolios.

You can edit:

Area	File
Text / Sections	index.html
Colors / Layout / Fonts	css/style.css
Animations / JS Logic	script/script.js
Images / Media	/images, video.mp4
🌐 Deployment

You can deploy easily on:

✔️ GitHub Pages

Push repo → Settings → Pages → Deploy

✔️ Netlify

Drag & Drop the folder → Done

✔️ Vercel

Click → New Project → Deploy
